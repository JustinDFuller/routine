# routine

This repository is currently in the product-planning phase for a personal iPhone app that helps track recurring routines in a visual, low-friction way.

Use the product brief as the source of truth for scope and behavior, the visual design spec for the app's visual and interaction language, the data design spec for data structures, storage, domain methods, views, and routing, and the system design for implementation architecture, build, deployment, testing, debugging, resilience, performance, security, accessibility, and tooling.
