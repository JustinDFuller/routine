Interface icons. The app uses Apple SF Symbols (proprietary); we substitute Lucide (MIT) path data — the closest clean, rounded line set.

```jsx
<Icon name="calendar" />
<Icon name="check" size={16} strokeWidth={3} />
```

Available: settings, pencil, calendar, check, plus, minus, trash, chevron-left, chevron-updown, reorder, x. Monochrome `currentColor`, stroke 2. For tappable controls use `IconButton` instead so the target stays 44×44.
