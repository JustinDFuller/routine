The soft capsule for a routine's count (`3/5`) and period (`week`). Fill is a faint tint of the card's ring accent.

```jsx
<MetadataPill accent="active">3/5</MetadataPill>
<MetadataPill accent="complete" emphasized>week</MetadataPill>
```

Match `accent` to the card's ring accent; set `emphasized` on completed cards (the stronger 0.14 tint). Not a status badge — Routine keeps decorative color low and never encodes status with color alone.
