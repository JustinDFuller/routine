The transient overlay shown after a completion — forgiving by design.

```jsx
<UndoBanner message="Completed Morning yoga" onUndo={fn} />
```

Elevated surface, an accent-tinted edge, and the app's single real shadow. Place near the bottom of the screen; it should dismiss on its own if ignored and never block scrolling. Keep the message plain (`Completed <name>`); the Undo action is a soft tinted capsule.
