Read the `readme.md` file within this skill, and explore the other available files
(`tokens/` for the exact color/type/spacing tokens, `components/core/` for the React
primitives and their `.prompt.md` usage notes, `ui_kits/routine_app/` for a full
interactive recreation, `guidelines/` for foundation specimens, `assets/` for the
app icons).

If creating visual artifacts (slides, mocks, throwaway prototypes, etc.), copy assets
out and create static HTML files for the user to view. If working on production code,
you can copy assets and read the rules here to become an expert in designing with this
brand.

Routine's essence: **dark-first, warm, calm, quietly precise — no gamification.**
Hold to it: role-based color (never color-alone signalling), the continuous progress
ring as the signature motif, sentence-case practical copy (never motivational —
no streaks/scores/celebration), flat border-defined surfaces, soft 16px card radii,
San Francisco type, and calm confirm-not-entertain motion. Substitute SF Symbols
with Lucide on the web and flag it.

If the user invokes this skill without any other guidance, ask them what they want to
build or design, ask some questions, and act as an expert designer who outputs HTML
artifacts _or_ production code, depending on the need.
